# 论文研究笔记写作规范（note-by-ai 适配版）

本文件是全部论文笔记的写作契约。每写一篇笔记前必须完整阅读本文件，并严格照此执行。
本版适配本项目：输入来自 MinerU 解析产物，输出统一落到 `note-by-ai/` 单文件夹。

---

## 0. 输入与输出

- **输入全文**：`<库根>/md/<STEM>_markdown/markdown.md`
  （由 MinerU 解析 PDF 得到，含正文、LaTeX 公式与图片引用）
  - 图片位于 `<库根>/md/<STEM>_markdown/images/`
  - 若 `markdown.md` 不存在，说明解析尚未完成 —— **立即停止，不要编造**，回复说明即可。
- **输出**：`<库根>/note-by-ai/<STEM>.md`
  - `<STEM>` = 源 PDF 文件名去扩展名（如 `Ainsworth_2006_DeFT`），是主键，不要改名。
  - 中文译名在「一、基本信息」中给出，并与一级标题一致。
  - 每个笔记文件独立，不写 README。
- **禁止修改**：`md/` 下的任何文件、解析产物、`_parse/` 等。

---

## 1. 语言要求（最高优先级）

1. 正文一律简体中文。
2. 学术名词/术语/模型/方法名首次出现时，中文后紧跟英文小括号：
   `图卷积网络（Graph Convolutional Network, GCN）`、`认知卸载（cognitive offloading）`。
3. 公式、数学符号不翻译，保留原文 LaTeX；变量名、上下标一律保留。
4. 代码、数据集、指标、模型缩写（GCN、BERT、AUC、RMSE…）保留英文。
5. 参考文献条目保留原文，不翻译作者名与期刊名。
6. 图片说明文字翻译成中文，保留英文图号（Figure 1 / Table 2）。

---

## 2. 公式要求（最高优先级）

**必须收录论文中的每一个公式，一个都不能遗漏。**

1. 行内 `$...$`，独立 `$$...$$`。
2. OCR 多余空格归一化：`H ^ {(i + 1)}` → `H^{(i+1)}`。
3. 保留原文编号 `\tag{1}`、`\tag{2}`，写在公式末尾。
4. 每个符号给出含义（矩阵/维度/激活函数/可学习参数…）。
5. 定理、引理、定义、证明中的公式也要全部收录，证明思路用中文复述。
6. 论文末设「附录 A：全文公式汇总」表格（编号 / 公式 / 含义）。
7. 若某公式原文是图片（MinerU 未识别为 LaTeX），在汇总表注明"见图片"并给出图片路径。

### 2.1 关于 MinerU 的公式/表格切图

`images/` 下会有 `*_equation_*.jpg`（公式切图）与 `*_table_*.jpg`（表格截图），但**正文 `markdown.md` 里未必有对应 `![]()` 引用**。判断"原文有没有这张图"不能只看正文引用，要到 `images/` 里核对。写附录 A/B 时应主动查找，它们是公式转写的视觉证据。

---

## 3. 内容详尽度要求

笔记要详尽，目标是让读者不读原文也能复现论文的方法与结论。必须覆盖：

| 维度 | 要求 |
| --- | --- |
| 问题动机 | 作者解决什么？现有方法为何不行？（有例子必写） |
| 记号体系 | 所有数学记号逐一定义 |
| 方法细节 | 模型结构、每模块作用、为何这样设计 |
| 理论分析 | 定理/引理/定义的完整陈述 + 证明思路 |
| 复杂度 | 时间/空间复杂度（若有） |
| 实验设置 | 数据集（规模/划分）、基线、超参、训练细节、评测指标 |
| 实验结果 | 关键数字逐项列 Markdown 表，不只说"更好" |
| 消融实验 | 若有，逐项说明结论 |
| 贡献 | 逐条列出 |
| 局限 | 原文自述局限 + 你的批判性评价 |
| 相关工作 | 与已有方法的具体区别（不是罗列） |

---

## 4. 标准章节结构（固定模板）

```markdown
# 研究笔记：<中文译名>（<English Title>）

> 本笔记由 MinerU 解析原始 PDF 后整理，公式按原文逐条收录。

## 一、基本信息（Basic Information）
（表格：英文标题 / 中文译名 / 作者 / 机构 / 发表 venue 与年份 / 代码链接 / 任务 / 关键词）

## 二、一句话概括（One-sentence Summary）
（1-3 句，说清"做了什么 + 为什么 + 结果如何"）

## 三、研究问题与动机（Problem and Motivation）

## 四、记号与预备知识（Notation and Preliminaries）

## 五、方法：<方法名>（Proposed Method）

## 六、理论分析（Theoretical Analysis）
（论文没有就整节删除，并在正文注明"原文未给出理论分析"）

## 七、实验设计（Experimental Design）

## 八、实验结果（Experimental Results）

## 九、相关工作（Related Work）

## 十、结论（Conclusion）

## 十一、批判性评价与启发（Critical Appraisal）
### 11.1 优点
### 11.2 局限与可质疑之处
### 11.3 与本课题（Learning Cognitive Structure）的关联
（延伸思考请明确标注"以下为笔记撰写者的延伸思考，非原文内容"）

## 附录 A：全文公式汇总（Formula Index）
（表格：编号 / 公式 / 含义）

## 附录 B：图表索引（Figure & Table Index）
（表格：编号 / 内容 / 文件路径）
```

灵活性：无理论分析则删第六节；综述类把"方法"改"综述框架与分类体系"；短论文相应精简，但**公式必须全部保留**。结构可调整，但详尽度与公式完整性不可打折。

---

## 5. 图片引用

- 用 `![中文图注](../md/<STEM>_markdown/images/page_1_image_body_0.jpg)` 引用确实存在的图片（路径相对 note-by-ai/）。
- 仅引用确实存在文件；图注写成 `图 N：<中文说明>`。
- 表格若原文是图片，也用图片引用，并在正文用 Markdown 表格重排内容（若 MinerU 已抽出则保留）。

---

## 6. 质量红线

1. **不得编造**：数字、引用、实验结果须与原文一致；不确定写"原文未明确说明"。
2. **不得遗漏公式**：硬性要求。
3. **不得只写摘要式概括**：展开方法细节与推导。
4. **不得整段照抄英文**：必须中文复述。
5. **表格数字对齐**：用 Markdown 表格，保留原文 ± 标准差。
6. 长度：宁详勿略。典型篇幅 2000–6000 字；公式多的论文可更长。

---

## 7. 排版细节

- 一级标题 `##`，二级 `###`，与模板一致。
- 每个二级标题后紧跟英文对照括号。
- 重要结论加粗。
- 公式与正文之间留空行。
- 文件末尾不写"以上"之类收尾客套话。
