# 8 种思维模型构建法

Stage 4 选用。每种配：适用场景、模板、示例。

## 总则：多候选呈现规则（必做）

访谈结束后，**不要只给一个模型，也不要让用户凭空起名**。正确姿势：

1. 根据萃取出的素材，挑 **2-3 种最适合的建模法**；
2. 用**用户自己的素材内容**，每种建模法各生成一个完整候选模型；
3. 并排展示（名称 + 结构 + 一句话解读），说明各自适合什么场景（讲课传播 / 贴墙速记 / 汇报展示）；
4. 请用户**挑一个 / 改一个 / 组合**——内容和命名权始终在用户。

> 原则：素材是用户的，AI 只做"同一素材的多种表达翻译"。候选可以多，但每个候选的内容都必须来自用户的原话与案例，不得引入用户没说过的观点。

---

## 1. 公式法（Formula）

**适用**：可表达为「X = A + B + C」或「做好 X = 准备度 × 方法 × 心态」的复合方法。

**模板**：
```
成果 = 因子1 + 因子2 + 因子3
或：成果 = 因子1 × 因子2 × 因子3
```

**示例**：拜访有效度 = 准备度 × 专业度 × 互动度

---

## 2. 二维矩阵（2D Matrix）

**适用**：两个对立维度构成 4 象限 / 9 宫格。

**模板**：
```
        维度 B 高        维度 B 低
维度 A 高 [象限1: 策略A]   [象限2: 策略B]
维度 A 低 [象限3: 策略C]   [象限4: 策略D]
```

**示例**：
- 客户 × 阶段 → 4 类应对策略
- 时间 × 投入度 → 精力分配矩阵

---

## 3. 层次法（Hierarchical / Pyramid / Funnel）

**适用**：分层结构，自顶向下或自底向上。

**模板**：
```
顶层：核心理念
  中层：3 大支柱
    底层：每支柱下 3 个要点
```

**示例**：金句塔（理念 / 原则 / 方法 / 工具）

---

## 4. 排比法（Parallelism）

**适用**：列举 3-5 个并列的"做到 X"或"不 X"原则。

**模板**：
```
做到 [动词1]、做到 [动词2]、做到 [动词3]、[达成结果]。
或：以 X 为始、以 Y 为中、以 Z 为终。
```

**示例**：
- 销售三铁：以客户为中心，以专业为依托，以共赢为目标。
- 拜访三不：不打断、不争论、不抢话。

---

## 5. 简写词集（Acronym）

**适用**：把多步过程压缩成一个容易传播的"词"。

**模板**：
```
取每步首字母（或谐音字）组成 4-5 字词
例：STAR = Situation / Task / Action / Result
例：FABE = Feature / Advantage / Benefit / Evidence
```

**示例**：销售准备的"知客配信"（知己 / 知客 / 配方案 / 信心态）

---

## 6. 英文字母（Initial-letter）

**适用**：与简写词类似，但用英文/拼音首字母，凸显国际感或简洁。

**模板**：
```
A = 步骤 1
B = 步骤 2
...
```

**示例**：PDCA / SMART / GROW

---

## 7. 口诀 / 顺口溜（Mnemonic Verse）

**适用**：要"让新人 30 秒记住"的方法。

**模板**：
```
四字一句 × 4 句 或 七字一句 × 2 句
节奏感强，押韵更佳
```

**示例**：
- 客户拜访"三看三问三切"：看衣着 / 看表情 / 看提问；问需求 / 问顾虑 / 问决策；切入点 / 切时机 / 切跟进。
- 4 句 7 字诀："开口先破冰 / 提问带倾听 / 总结要回放 / 收尾明确下一步"

---

## 8. 三字经（Three-Character Classic）

**适用**：文化型传播、培训行业术语。

**模板**：
```
人之初 / 性本善 / 性相近 / 习相远（古例）
[主题] × 1 / [主题] × 2 / [主题] × 3
```

**示例**：
- 萃取心法：深挖潜、问到底、汇成典、传帮带。

---

## 选型决策树

```
任务是流程还是原则？
  ├── 流程 → 步骤多少？
  │     ├── 3-5 步 → 简写词 或 英文字母 或 口诀
  │     └── 6+ 步 → 层次法
  ├── 原则 → 有几个并列？
  │     ├── 3-5 → 排比 或 三字经
  │     └── 复合 → 公式
  └── 涉及对比维度 → 二维矩阵
```
