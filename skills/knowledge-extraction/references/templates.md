## §SOP — 操作手册 / 标准作业指引

### 模板结构
```
# [岗位名] [任务名] 操作手册

## 1. 适用对象与场景
[谁用、什么场景下用]

## 2. 前置准备
- 工具：[用到什么软件 / 表单 / 物料]
- 信息：[需要哪些客户资料 / 数据]
- 心态：[应该是什么态度]

## 3. 操作步骤

### 步骤 1: [动宾结构]
- 动作：[做什么]
- 标准：[做到的标志]
- 时长：[多长时间]
- 关键提示：[常见错误 / 注意事项]

### 步骤 2: ...
...

## 4. 关键节点控制
| 节点 | 必须做对的事 | 出错后果 |
|---|---|---|
| 节点 1 | ... | ... |
| 节点 2 | ... | ... |

## 5. 工具 / 表单
- 表单 A：[名称 / 用途 / 填写示例]
- 工具 B：[工具 / 命令 / 操作路径]

## 6. 常见问题与解答
Q1: [高频问题]
   A: [推荐应对]
Q2: ...
```

### 适用 Skill 的工作流
导出为 Word / Markdown 文件，使用 WorkBuddy 的文档创建路径。

## §Course — 培训课纲

### 模板结构（基于二级大纲"清工痛简匀"原则）
```
# 课程名（[时长]，[受众]）

## 课程目标
完成本课程后，学员能够：
1. [动词 + 宾语 + 标准]（知识）
2. ...（技能）
3. ...（态度 / 决策）

## 二级大纲（清工痛简匀 = 串并联清晰 / 结构工整 / 直击痛点 / 3-7 条 / 匀称）

### 模块 1: [模块名]
- 1.1 [知识点]
- 1.2 [知识点]
- ...
- 教学活动：[案例分析 / 演练 / 测评]

### 模块 2: ...
...

## 课程时长分配
| 模块 | 时长（分钟） | 占比 |
|---|---|---|
| 模块 1 | ... | ... |
| ...

## 教学方法
- 讲授：[%]
- 案例：[%]
- 演练：[%]
- 测评：[%]

## 评估方式
- 课后测验：[题型 / 通过标准]
- 实操考核：[场景 / 通过标准]
```

### 适用
导出一份 .pptx 课纲（用 tencent-pptx skill 创建）。

## §Case — 案例（STAR / 高峰体验）

### STAR 案例模板
```
# 案例标题（情境 + 冲突 + 行动 + 结果）

## 情境 (Situation)
[背景、客户特征、行业、时机]

## 任务 (Task)
[要解决的核心问题 / 达成的目标]

## 行动 (Action)
- 做了什么关键动作
- 为什么这么做（关键判断）
- 怎么克服阻力

## 结果 (Result)
- 可量化结果：[数字 / 比例]
- 客户反馈 / 后续影响
- 复盘出的"手法"
```

### 高峰体验案例模板（隐性经验专用）
```
# [高峰事件标题]

## 背景
[情境]

## 挑战
[最棘手的事]

## 想法（为什么要这么做）
[当时内心真正在盘算什么]

## 说法 + 做法
- 说了：[关键话术]
- 做了：[关键动作 / 信号捕捉]

## 关键措施
[真正起决定作用的那 1-2 步]

## 优化
[事后哪里可以再改进]

## 可复用的"手法"
[从这件事里抽出的、别人也能学的判断 / 反应]
```

### 适用
保存为 Word / 飞书文档 / 培训素材库。
