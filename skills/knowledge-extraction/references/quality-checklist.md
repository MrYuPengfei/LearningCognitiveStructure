# 道法术器坑 — 质量自检清单

每一份交付物在交给用户前，**必须**跑一遍本清单。任何一项不达标，回到对应阶段继续萃取。

---

## 道（本质 / 价值观 / 哲学）

**问**：
- [ ] 这份方法论背后**最核心的理念**是什么？能用一句话说清吗？
- [ ] 这个理念**是否能解决学员心中的根本困惑**？
- [ ] 它和岗位 / 行业的**底层逻辑**相符吗？

**未达标的表现**：
- 通读全文找不到"为什么这样做"——只有怎么做。
- 多个任务的"道"互相矛盾。

**补救**：回到 Stage 4 的"要拔高"步骤，强制写出 1 句核心理念，并以此为锚重审各任务。

---

## 法（思维规律 / 原则 / 决策准则）

**问**：
- [ ] 萃取出了**可推导的规则 / 原则**吗？（不是动作，而是判断标准）
- [ ] 这些规则**能在不同场景下复用**吗？

**未达标的表现**：
- 只有 What / How，没有"在什么情况下做 / 不做"。
- 学员读完仍不知道**何时该选哪个动作**。

**补救**：在 Stage 3 后增加"原则抽取"环节，把共性做法升级为判断准则。

---

## 术（方法 / 步骤 / 操作技巧）

**问**：
- [ ] 每一步都有**具体的动作描述**（不是抽象的"做好沟通"）吗？
- [ ] 步骤**前后衔接**自洽吗？
- [ ] 是否区分了"做了 / 做好 / 做到极致"三档？

**未达标的表现**：
- 步骤是"准备 → 执行 → 跟进"这种空话。
- 缺少让新手能模仿的颗粒度。

**补救**：在 Stage 5 输出模板里强制填每一步的"动作 / 标准 / 时长 / 关键提示"。

---

## 器（工具 / 表单 / 系统）

**问**：
- [ ] 提到的工具、表单、系统**都列出来了**吗？路径、操作方法明确吗？
- [ ] 这些工具**新人能直接拿到**吗？还是依赖个人资源？

**未达标的表现**：
- 只列了"用 CRM"，但没说用哪个模块、哪个字段。
- 没有可下载 / 可复制的表单。

**补救**：把所有"工具 / 表单"列成清单，每项注明"在哪、怎么用、模板在哪"。

---

## 坑（陷阱 / 注意事项 / 易错点）

**问**：
- [ ] 列出了**至少 3 条新手最容易踩的坑**吗？
- [ ] 每条坑都附了"如何识别 + 如何规避"吗？
- [ ] 是否有**高手不会告诉你的盲区**（隐性经验里挖出的）？

**未达标的表现**：
- 完全没有"坑"段落。
- 坑写得无关痛痒（"注意认真沟通"这种废话）。

**补救**：回到 Stage 3 的"隐性经验"环节，专门用"踩坑 / 失败案例"补充。

---

## 综合检查：3 个 meta 问题

1. **可迁移性**：另一个完全不同的岗位 / 行业，能用这套方法的"骨架"（去掉岗位-specific 内容）吗？
2. **可执行性**：一个新入职的人，仅凭这份文档能在 30 天内达到现有高手的 80% 水平吗？
3. **可验证性**：是否能在**演练 / 测试中检验**萃取的效果？

如果以上 meta 问题有 ≥1 个答"否"，重新评估是 Stage 几没做透。

---

## 自检输出格式

完成后对用户输出一份自检报告：

```

✅ 术：达标 / 改进：[建议]
✅ 器：达标 / 改进：[建议]
✅ 坑：达标 / 改进：[建议]

📊 综合评分：[X/5]

📝 待优化项（按优先级）：
1. ...
2. ...
```
